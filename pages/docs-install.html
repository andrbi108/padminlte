صفحهٔ بعد
این صفحهٔ مستندات کاملاً کاربردی است: همهٔ دستورها واقعی‌اند، بلوک‌های کد با یک کلیک کپی می‌شوند و بدون اینترنت هم قابل استفاده‌اند.

پیش‌نیازها

PAdminLTE یک پروژهٔ صفر-وابستگی است: هیچ npm، webpack، vite یا CDN لازم نیست و هیچ مرحلهٔ build وجود ندارد. فقط چهار فایل پروژه کنار صفحات HTML شما باشند:

فایلنقش
css/padminlte.cssکل سیستم طراحی (توکن‌ها + کامپوننت‌ها)
js/pa-icons.jsتزریق خودکار SVG از ویژگی data-pa-icon
js/padminlte.jsهستهٔ runtime (مدال، توست، تم، چارت، فرم و…)
js/pa-layout.jsتزریق خودکار sidebar / header / footer

هیچ‌کدام از این فایل‌ها چیزی از خارج fetch نمی‌کنند؛ به همین دلیل پروژه روی file:// هم سالم اجرا می‌شود.

سه روش اجرا

روش ۱ — اجرای مستقیم از file://

ساده‌ترین راه: فایل index.html را در مرورگر باز کنید. برای ارزیابی سریع و استفادهٔ آفلاین کامل کافی است.

# لینوکس / مک
xdg-open index.html      # یا: open index.html

# ویندوز
start index.html

روش ۲ — سرور محلی

اگر می‌خواهید localStorage در همهٔ مرورگرها (از جمله Chrome روی file://) بدون محدودیت کار کند:

# با Python 3
python3 -m http.server 8080

# با Node.js (بدون نصب پکیج)
npx --yes serve -l 8080 .

# یا با PHP
php -S localhost:8080

سپس به http://localhost:8080 بروید.

روش ۳ — میزبان استاتیک

پوشهٔ کامل پروژه را روی هر میزبان استاتیک (GitHub Pages، Netlify، Vercel، Cloudflare Pages، S3، Nginx، Apache، Caddy و…) آپلود کنید. هیچ تنظیم build لازم نیست؛ همهٔ مسیرها نسبی‌اند.

پیکربندی اولیه

۱) اسکلت یک صفحهٔ جدید

هر صفحهٔ PAdminLTE از همین اسکلت ساخته می‌شود. آن را کپی کنید و عنوان و محتوای خود را جایگزین کنید:

<!doctype html>
<html lang="fa" dir="rtl" data-pa-theme="light">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>PAdminLTE — عنوان صفحه</title>
  <link rel="stylesheet" href="css/padminlte.css">
</head>
<body>
  <a class="pa-skip-link" href="#pa-main-content">پرش به محتوا</a>
  <div class="pa-app">
    <div data-pa-layout="sidebar"></div>
    <div class="pa-main">
      <div data-pa-layout="header"></div>
      <main class="pa-content" id="pa-main-content">
        <!-- محتوای شما -->
        <div data-pa-layout="footer"></div>
      </main>
    </div>
  </div>
  <script src="js/pa-icons.js"></script>
  <script src="js/padminlte.js"></script>
  <script src="js/pa-layout.js"></script>
</body>
</html>

ترتیب سه اسکریپت پایانی مهم است: pa-icons.js آیکن‌ها را تعریف می‌کند، padminlte.js رفتارها را راه می‌اندازد و pa-layout.js در آخر سایدبار/هدر/فوتر را تزریق و دوباره boot می‌کند.

۲) زبان و جهت صفحه

صفحات نمونه با راست‌به‌چپ شروع می‌شوند. برای چپ‌به‌راست کافی است:

<html lang="en" dir="ltr">

یا در زمان اجرا (در localStorage با کلید pa-dir ذخیره می‌شود):

PAdminLTE.setDir('ltr');   // یا 'rtl'

۳) تم پیش‌فرض

روی تگ html مقدار data-pa-theme را light یا dark بگذارید، یا در زمان اجرا:

PAdminLTE.setTheme('dark');

انتخاب کاربر دکمهٔ ماه/خورشید هدر، در localStorage با کلید pa-theme ذخیره می‌شود و در بازدید بعدی خودکار اعمال می‌گردد.

۴) شخصی‌سازی برند و منوی سایدبار

سایدبار از آرایهٔ sections در js/pa-layout.js ساخته می‌شود. برای افزودن صفحهٔ خود، یک آیتم به هر بخش اضافه کنید:

{ href: 'pages/my-page.html', icon: 'star', label: 'صفحهٔ من' }

و برند بالای منو:

PAdminLTE.layout.apply({
  sidebar: { brand: 'پنل شرکت من', brandMark: 'ش' }
});

۵) چک‌لیست راه‌اندازی

  • چهار فایل اصلی در مسیرهای css/ و js/ کنار صفحه هستند.
  • lang و dir روی تگ html درست تنظیم شده‌اند.
  • سه اسکریپت پایانی به همان ترتیبِ اسکلت بالا قرار دارند.
  • در کنسول مرورگر خطای قرمز یا هشدار [PAdminLTE] Unknown icon: وجود ندارد.
  • سایدبار، هدر و فوتر تزریق شده‌اند (به‌جای data-pa-layout خالی، محتوای واقعی می‌بینید).

استقرار روی میزبان‌های معروف

GitHub Pages

git init
git add .
git commit -m "feat: initial PAdminLTE import"
git branch -M main
git remote add origin https://github.com/<USER>/padminlte.git
git push -u origin main

سپس Settings → Pages → Deploy from a branch را روی شاخهٔ main و پوشهٔ / (root) تنظیم کنید. سایت روی https://<USER>.github.io/padminlte/ در دسترس قرار می‌گیرد.

Netlify (کشیدن و رها کردن)

پوشهٔ پروژه را در app.netlify.com/drop رها کنید — در چند ثانیه URL عمومی می‌گیرید. برای CLI:

npm install -g netlify-cli
netlify deploy --dir=. --prod

Nginx

server {
    listen 80;
    server_name padminlte.local;
    root /var/www/padminlte;
    index index.html;
    charset utf-8;
    location / { try_files $uri $uri/ /index.html; }
    gzip on;
    gzip_types text/css application/javascript text/html application/json;
}

راهنمای کامل Apache، Vercel و ورک‌فلؤ GitHub Actions در docs/INSTALL.md آمده است.

عیب‌یابی سریع

مطمئن شوید js/pa-icons.js قبل از js/padminlte.js لود شده است. در کنسول به دنبال هشدار [PAdminLTE] Unknown icon: بگردید — یعنی نام آیکن اشتباه است. برای محتوای پویا، PAdminLTE.injectIcons(root) را روی زیردرخت جدید صدا بزنید.

Chrome روی file:// به‌طور پیش‌فرض localStorage را محدود می‌کند. کد با try/catch امن نوشته شده و برنامه نمی‌شکند، اما برای ذخیرهٔ تنظیمات از سرور محلی یا میزبان استاتیک استفاده کنید.

وجود <div data-pa-layout="sidebar"></div> و <div data-pa-layout="header"></div> در صفحه و لود شدن js/pa-layout.js را بررسی کنید و خطاهای کنسول را ببینید.

کش مرورگر را دور بزنید: Ctrl+Shift+R (ویندوز/لینوکس) یا Cmd+Shift+R (مک)، یا در DevTools گزینهٔ Disable cache را روشن کنید.
