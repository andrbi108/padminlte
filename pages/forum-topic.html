سلام به همه‌ی دوستان عزیز،

مدت زیادی است که با JavaScript کار می‌کنم و حالا می‌خواهم وارد دنیای React شوم. با توجه به تغییرات زیاد اکوسیستم در سال ۲۰۲۴ (Next.js 14، Server Components، React 19 و…) کمی سردرگم شده‌ام. خواستم از تجربه‌ی شما بپرسم که بهترین مسیر یادگیری React در حال حاضر چیست؟

سوالات مشخصی که دارم:

  • آیا بهتر است ابتدا با Create React App شروع کنم یا مستقیم به Next.js بروم؟
  • منابع آموزشی به‌روز و فارسی پیشنهادی شما چیست؟
  • چقدر باید روی TypeScript تمرکز کنم؟
  • پروژه‌های تمرینی خوب برای شروع چه هستند؟

ممنون می‌شوم اگر تجربه‌ها و منابع خود را به اشتراک بگذارید. هدفم این است که در ۳ ماه آینده به سطح قابل‌قبولی برسم.

سلام امیر، خوش‌آمدی به دنیای React!

پیشنهاد من این است که مستقیم با Next.js 14 شروع کنی. امروزه Create React App تقریباً منسوخ شده و جامعه‌ی React به‌سمت فریم‌ورک‌های مبتنی بر آن حرکت کرده. با Next.js هم می‌توانی صفحات ساده بسازی و هم به‌تدریج با Server Components و App Router آشنا شوی.

برای منابع فارسی، مستندات رسمی React (react.dev) ترجمه‌ی خوبی دارد و بسیار به‌روز است. برای پروژه‌ی تمرینی هم ساخت یک اپلیکیشن لیست کارها با امکان فیلتر و جستجو، شروع عالی‌ای خواهد بود.

موافقم با سارا. یک نکته‌ی مهم دیگر: TypeScript را از همان روز اول یاد بگیر. امروزه بیش از ۸۰٪ موقعیت‌های شغلی React نیازمند TypeScript هستند و یادگیری آن بعداً سخت‌تر می‌شود.

برای منابع انگلیسی هم پیشنهاد می‌کنم دوره‌ی Epic React از Kent C. Dodds و ویدیوهای Theo (t3.gg) روی YouTube را ببینی. هر دو بسیار کاربردی و به‌روز هستند.

من خودم همین مسیر را ۶ ماه پیش طی کردم. تجربه‌ام این بود که ابتدا ۲ هفته فقط روی مفاهیم پایه‌ی React (Components، Props، State، useEffect) متمرکز شدم و بعد وارد Next.js شدم.

یک توصیه: حتماً با یک پروژه‌ی واقعی کار کن، نه فقط تمرین‌های جزئی. من یک کلون کوچک از توییتر ساختم و چیزهای زیادی یاد گرفتم. موفق باشی!

یک نکته‌ی مهم که دوستان نگفتند: مفاهیم JavaScript مدرن را قبل از ورود به React تسلط داشته باش. مخصوصاً:

  • destructuring و spread/rest operators
  • arrow functions و closure
  • Promise و async/await
  • متدهای آرایه (map، filter، reduce)

بدون این پایه‌ها، یادگیری React دردناک خواهد بود. موفق باشی!
