مرجع API

خانه › مستندات › مرجع API
همهٔ توابع روی شیء جهانی PAdminLTE در دسترس‌اند. این صفحه خلاصهٔ پرکاربردترین‌هاست؛ فهرست کامل با جزئیات در docs/API.md آمده است.

ظاهر و پوسته (Theme / Dir / Sidebar)

تابعکارنمونه
getTheme() / setTheme(t)خواندن/تنظیم تم 'light' یا 'dark'PAdminLTE.setTheme('dark')
toggleTheme()جابجایی بین دو تمPAdminLTE.toggleTheme()
getDir() / setDir(d)خواندن/تنظیم جهت 'rtl' یا 'ltr'PAdminLTE.setDir('ltr')
toggleDir()جابجایی جهت صفحهPAdminLTE.toggleDir()
getSidebarState() / setSidebarState(s)وضعیت سایدبار 'normal' یا 'mini'PAdminLTE.setSidebarState('mini')
toggleSidebar()جمع/باز کردن سایدبارPAdminLTE.toggleSidebar()

مدال، توست و بازخورد

تابعکارنمونه
openModal(sel)باز کردن مدال با سلکتور بک‌دراپPAdminLTE.openModal('#crud-modal')
closeModal(sel)بستن مدالPAdminLTE.closeModal('#crud-modal')
toast(o)نمایش اعلان شناورtoast({kind:'success', title:'…', message:'…'})
notify(o)افزودن آیتم به فهرست اعلان‌های هدرnotify({title:'…'})
btnLoading(btn, on)حالت بارگذاری روی دکمهbtnLoading(el, true)
loader.show()/hide()پوشش بارگذاری تمام‌صفحهPAdminLTE.loader.show()
copyToClipboard(t)کپی متن (Promise)copyToClipboard('متن')
lightbox.open(items, i)نمایش گالری نوربه‌کار رفته در صفحهٔ گالری

نمودارهای بومی (Canvas)

تابعنوع نمودار
lineChart(canvas, data, opts)خطی — با انیمیشن رسم و tooltip
barChart(canvas, data, opts)میله‌ای — عمودی/افقی
donutChart(canvas, data, opts)دونات/دایره‌ای با درصد وسط
sparkline(canvas, data, opts)نمودار کوچک تک‌سری برای ویجت‌ها

در اکثر موارد نیازی به فراخوانی مستقیم نیست؛ ویژگی data-pa-chart="line|bar|donut|sparkline" روی <canvas> کافی است. برای رندر مجدد با دادهٔ تازه، همان تابع را دوباره روی همان canvas صدا بزنید.

رویدادها و boot

سیستم رویداد داخلی برای هماهنگی بین کامپوننت‌ها:

PAdminLTE.on('pa:theme', function (e) {
  console.log('تم عوض شد:', e.detail.theme);
});

PAdminLTE.emit('pa:theme', { theme: 'dark' });

رویدادهای منتشرشدهٔ داخلی: pa:theme، pa:dir، pa:sidebar، pa:modal-open، pa:modal-close، pa:wizard-step، pa:net و…

برای محتوای تزریق‌شدهٔ پویا (AJAX خودتان)، زیردرخت جدید را دوباره راه‌اندازی کنید:

PAdminLTE.boot(newNode);
نصب و پیکربندی اولیه راهنمای استفاده سفارشی‌سازی و تم
