پرسش‌های پرتکرار

۱. آیا PAdminLTE واقعاً هیچ وابستگی خارجی ندارد؟

بله. این نسخه از هیچ کتابخانه خارجی (Bootstrap، jQuery، Chart.js، Font Awesome و...) استفاده نمی‌کند. همه‌چیز با HTML، CSS و JavaScript خالص (vanilla) و به‌صورت فایل‌های محلی ارائه شده است.

۲. آیا می‌توانم فایل‌ها را با file:// باز کنم؟

بله. هیچ نیازی به سرور وب نیست. کافی است فایل index.html را در مرورگر باز کنید. در صورتی که بخواهید سرور محلی هم استفاده کنید، می‌توانید از python3 -m http.server استفاده کنید.

۳. چطور تم تاریک/روشن را تغییر دهم؟

روی آیکون ماه/خورشید در نوار بالا کلیک کنید یا از صفحه‌ی تنظیمات استفاده کنید. انتخاب شما در localStorage ذخیره می‌شود.

۴. آیا RTL پشتیبانی می‌شود؟

بله، PAdminLTE به‌صورت پیش‌فرض RTL است. می‌توانید با دکمه‌ی تغییر جهت در نوار بالا، به LTR سوئیچ کنید. جهت انتخابی نیز در localStorage ذخیره می‌شود.

۵. نمودارها با چه ابزاری ساخته می‌شوند؟

همه‌ی نمودارها (خطی، میله‌ای، دونات و اسپارک‌لاین) با Canvas API بومی مرورگر و بدون کتابخانه خارجی (مانند Chart.js) رسم می‌شوند.

۶. آیا می‌توانم رنگ‌ها را سفارشی کنم؟

بله. تمام رنگ‌ها به‌صورت CSS Custom Properties در فایل css/padminlte.css در بخش :root تعریف شده‌اند. می‌توانید مقادیر را مستقیماً ویرایش کنید. برای جزئیات بیشتر docs/CUSTOMIZE.md را ببینید.

۷. چه مرورگرهایی پشتیبانی می‌شوند؟

هر مرورگر مدرن (Chrome 90+، Firefox 88+، Safari 14+، Edge 90+) که از CSS Custom Properties، Flexbox، Grid و ES2017 پشتیبانی می‌کند. بدون نیاز به polyfill.
