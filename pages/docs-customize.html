سفارشی‌سازی و تم

خانه › مستندات › سفارشی‌سازی و تم
تمام رنگ‌ها، فاصله‌ها و اندازه‌ها به‌صورت متغیر CSS در :root فایل css/padminlte.css تعریف شده‌اند. کافی است همان‌جا مقدارها را عوض کنید — همهٔ کامپوننت‌ها خودشان تبعیت می‌کنند.

تغییر رنگ برند

برای تغییر رنگ اصلی (دکمه‌ها، لینک‌ها، آیتم فعال سایدبار و…) فقط این دو متغیر را عوض کنید:

:root {
  --pa-primary:      #6f42c1;  /* رنگ اصلی */
  --pa-primary-soft: #e4d9f7;  /* تینتِ روشن همان رنگ برای پس‌زمینه‌ها */
}

می‌توانید بدون دست‌زدن به فایل اصلی، یک فایل CSS کوچک هم بعد از padminlte.css لود کنید:

<link rel="stylesheet" href="css/padminlte.css">
<link rel="stylesheet" href="css/my-brand.css">  <!-- overrideها -->

پالت فعلی

از چپ: primary، secondary، success، info، warning، danger، dark — همان‌هایی که در کلاس‌های pa-btn-* و pa-badge-* استفاده می‌شوند.

تم تیره

تم تیره فقط با یک ویژگی روی تگ html فعال می‌شود؛ خود صفحه رنگ‌های سطح را از بلوک [data-pa-theme="dark"] می‌خواند:

<html data-pa-theme="dark">

چیدمان و منو

سایدبار مینی

کلاس pa-sidebar-mini روی .pa-app سایدبار را به حالت آیکن‌خالی جمع می‌کند. حالت انتخابی کاربر در localStorage با کلید pa-sidebar ذخیره می‌شود و در دکمهٔ همبرگر هدر همین کار انجام می‌شود.

افزودن صفحهٔ جدید به منو

در js/pa-layout.js آرایهٔ sections منبع یگانهٔ منوست؛ صفحهٔ خود را به هر بخش اضافه کنید تا هم در سایدبار و هم در پالت فرمان (Ctrl+K) ظاهر شود:

{
  title: 'بخش من',
  items: [
    { href: 'pages/my-page.html', icon: 'star', label: 'صفحهٔ من' }
  ]
}

زیرمنو (درخت)

به‌جای items از tree استفاده کنید؛ گروه با کلیک باز و بسته می‌شود و اگر یکی از زیرآیتم‌ها فعال باشد، گروه به‌صورت خودکار باز نگه داشته می‌شود:

{
  title: 'مدیریت کاربر',
  tree: [
    { name: 'حساب کاربری', icon: 'user', items: [
      { href: 'pages/account.html', icon: 'user_cog', label: 'حساب من' }
    ]}
  ]
}

دسترسی‌پذیری و چاپ

  • حرکت کاهش‌یافته: اگر کاربر در سیستم‌عامل «Reduce motion» را فعال کرده باشد، انیمیشن‌ها و ظهورها خودکار غیرفعال می‌شوند (prefers-reduced-motion).
  • چاپ: استایل @media print سایدبار/هدر را حذف می‌کند، سربرگ جداول را در هر صفحه تکرار می‌کند و آدرس لینک‌ها را چاپ می‌کند. با data-pa-no-print هر المان را از چاپ حذف کنید.
  • پرش به محتوا: اولین Tab هر صفحه لینک «پرش به محتوا» را نشان می‌دهد.
