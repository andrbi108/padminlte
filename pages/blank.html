شروع کنید

این یک صفحه خالی است. از این قالب به‌عنوان نقطه شروع برای ساخت صفحات جدید پروژه‌ی خود استفاده کنید.

کافی است ساختار پایهٔ زیر را کپی کنید و محتوای خود را درون <main class="pa-content"> قرار دهید. تمام وابستگی‌ها محلی هستند و صفحه بدون نیاز به سرور، مستقیماً از طریق file:// اجرا می‌شود.

می‌توانید از کامپوننت‌های آمادهٔ قالب استفاده کنید: کارت جدول فرم نمودار مدال بج

اسکلت پایهٔ HTML

<!doctype html>
<html lang="fa" dir="rtl" data-pa-theme="light">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>PAdminLTE — عنوان صفحه</title>
  <link rel="stylesheet" href="../css/padminlte.css">
</head>
<body>
  <a class="pa-skip-link" href="#pa-main-content">پرش به محتوا</a>
  <div class="pa-app">
    <div data-pa-layout="sidebar"></div>
    <div class="pa-main">
      <div data-pa-layout="header"></div>
      <main class="pa-content" id="pa-main-content">
        <div class="pa-page-header">
          <div>
            <h1>عنوان صفحه</h1>
            <div class="pa-breadcrumb">
              <a href="../index.html">خانه</a>
              <span class="pa-sep">›</span>
              <span>عنوان صفحه</span>
            </div>
          </div>
        </div>

        <!-- محتوای شما اینجا -->

        <div data-pa-layout="footer"></div>
      </main>
    </div>
  </div>
  <script src="../js/pa-icons.js"></script>
  <script src="../js/padminlte.js"></script>
  <script src="../js/pa-layout.js"></script>
</body>
</html>

نکات کلیدی

  • سه اسکریپت پایانی را به همان ترتیب قرار دهید؛ pa-icons.js آیکن‌ها را تزریق می‌کند، padminlte.js رفتارها را راه‌اندازی می‌کند و pa-layout.js سایدبار/هدر/فوتر را به‌صورت خودکار تزریق می‌کند.
  • برای آیکن‌ها از ویژگی data-pa-icon="name" استفاده کنید تا SVG به‌صورت خودکار درج شود.
  • برای جداول تعاملی از ویژگی data-pa-datatable روی <table> استفاده کنید.
  • برای نمودارها از data-pa-chart="line|bar|donut|sparkline" روی <canvas> استفاده کنید.
  • برای مدال‌ها و توست‌ها از PAdminLTE.openModal() و PAdminLTE.toast() استفاده کنید.
