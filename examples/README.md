# Examples

این پوشه برای نمونه‌های اضافی و قالب‌های کامل‌تر صفحه‌ها رزرو شده است.

در نسخهٔ ۱.۰.۰، خود صفحات در `pages/` و ریشهٔ پروژه قرار دارند و به‌عنوان نمونه‌های اصلی استفاده می‌شوند.

## شروع سریع

ساده‌ترین راه برای شروع، کپی کردن `pages/blank.html` به یک فایل جدید و ویرایش محتوای آن است:

```bash
cp pages/blank.html pages/my-page.html
```

سپس فایل را در مرورگر باز کنید.

برای راهنمای کامل به [`docs/USAGE.md`](../docs/USAGE.md) مراجعه کنید.
